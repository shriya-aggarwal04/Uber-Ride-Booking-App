#  Uber Ride Booking App (MERN Stack)

A full-stack Uber-style ride booking web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).  
The project demonstrates real-world ride booking functionality including authentication, fare calculation, and live ride tracking.

---

##  Project Overview

This application simulates a real-time ride booking system similar to Uber.  
It is designed to showcase backend API design, authentication, real-time communication, and frontend integration using modern MERN stack practices.

---

##  Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication & Security
- JWT (JSON Web Tokens)
- bcrypt

### APIs & Tools
- Google Maps API
- Socket.IO

---

##  Features

- User signup and login
- JWT-based authentication and authorization
- Ride booking functionality
- Distance and time calculation using Google Maps API
- Fare estimation based on distance
- Live ride tracking
- User and driver role handling
- RESTful API architecture
- Responsive user interface

---



##  How to Use This Project

If you want to use or extend this project:

1. Fork the repository to your GitHub account  
2. Clone the forked repository to your local system  
3. Configure required environment variables (MongoDB, JWT, Google Maps API)  
4. Customize features such as pricing logic, UI, or roles  
5. Deploy the project using platforms like Render, Vercel, or AWS  

API keys and secrets must be added manually and should never be committed to GitHub.
